# -📊 Дашборд: Анализ экосистемы велопроката Bay Area BikeshareЦель проекта:Комплексный анализ показателей сети городского велопроката в районе залива Сан-Франциско для оптимизации инфраструктуры и маркетинга.🛠 Ключевые разделы отчета:Операционные тренды [A]:Мониторинг объемов поездок и динамики прироста (MoM, QoQ, YoY).Оценка среднего ежедневного объема и паттернов по дням недели.Тепловая карта часов пик (выделены интервалы 08:00–09:00 и 17:00–18:00) и анализ пиковых месяцев в Сан-Хосе.География и Инфраструктура [B, C]:Интарактивная карта станций по точным гео-координатам с функцией детализации (Drillthrough).Выявление недоиспользуемых станций ($<5$ поездок/день) для релокации.Рейтинг самых популярных маршрутов (Start ➔ End).Сегментация пользователей [D]:Сравнительный анализ Subscribers (подписчики — $80\%+$ поездок, короткие поездки по будням) и Customers (разовые клиенты — длительные прогулочные поездки в выходные).Демографический профиль по полу и возрасту.
